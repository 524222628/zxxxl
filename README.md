# 关西，八日慢行 · v1.0

这是一个移动端优先的关西八日互动行程手册，覆盖 2026 年 9 月 27 日至 10 月 4 日的大阪、神户、京都与关西机场路线。页面以时间轴为入口，按日期切换单一当前行程，减少手机端阅读时的跳转与信息干扰。

## 在线页面

- GitHub Pages：<https://524222628.github.io/zxxxl/>
- 发布分支：`v1.0`

## 功能

- D1–D8 日期导航与 hash 深链接，切换日期后默认选中当天第一项。
- 线性时间轴：点击时间节点即可切换当前行程并保持时间轴居中。
- 单行程阅读流：当前卡片完整展示时间、行动、地点、交通、提示与照片图库。
- 每日“出发前再检查”提示、当天点位地图与 Google Maps 外部导航。
- 大阪、京都官方线路图预览，支持独立大图查看与缩放。
- 行程照片采用轻量预览、按需加载原图及前后照片预取，缩略图支持拖动与单击切换。
- 移动端固定布局与禁止页面整体缩放，地图和图库保留独立查看能力。

## 项目结构

```text
index.html              页面入口
app.js                  路由、时间轴、单行程与图库逻辑
styles.css              响应式样式与视觉 tokens
data/itinerary.json     八日行程数据（含 D3 神户路线）
assets/images/           行程照片与线路图
assets/photo-previews/   首屏使用的轻量预览图
server.js               本地静态服务与只读数据接口
```

## 本地运行

```powershell
npm start
```

打开 <http://localhost:4173/>；若直接使用静态文件，也可以打开 `index.html`，但本地服务能提供完整的数据读取与缓存行为。

## 验证

```powershell
node --check app.js
npm test
```

页面为公开只读展示，行程中的班次、营业时间、站台、天气与地图位置仍应以出发当天官方信息为准。
